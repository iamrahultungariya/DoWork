# Get Shit Done (GSD): Spec-Driven Execution Protocol

## Purpose
Enforces disciplined, milestone-driven execution with atomic validation steps and state integrity.

## Core Directives
1. **Spec Alignment**: Every task maps to written requirements, explicit data models, and verified interfaces.
2. **Atomic Milestones**: Work proceeds in distinct stages (Turn 1: Foundations & Rules; Turn 2: Skeleton & Structure; Turn 3: Home Page Implementation).
3. **No Code Degradation**: Never add dead code, duplicate stores, or bloated files.
4. **Loc Limit**: Keep all files strictly under 500 lines of code. Reusable UI components must be modular and single-responsibility.
5. **State Synchronicity**: Update markdown architecture documents (`STORES.md`, `FUNCTIONS.md`, `FEATURES_MAP.md`) whenever schemas, functions, or features evolve.
